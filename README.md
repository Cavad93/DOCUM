# Telegram Medical Bot

Telegram бот для автоматического создания шаблонов медицинских осмотров с использованием Claude AI.

## Возможности

- **Распознавание фото документов (OCR)**: Автоматическое извлечение ФИО, даты рождения и СНИЛС с фотографий документов
- **Ввод данных текстом**: Возможность вручную ввести данные пациента
- **Генерация шаблонов осмотра**: Создание детальных медицинских шаблонов на основе готовых шаблонов клиник
- **Поддержка двух клиник**:
  - Клиника "Династия"
  - Клиника "ПСКП"
- **Система подтверждения**: Проверка и утверждение шаблона перед сохранением
- **Итеративные правки**: Возможность запросить исправления с комментариями
- **Архивирование шаблонов**: Сохранение всех созданных шаблонов с возможностью поиска

## Используемые технологии

- **Python 3.9+**
- **Claude AI** (Anthropic):
  - `claude-sonnet-4-5-20250929` (Claude Sonnet 4.5) - для OCR и распознавания документов
  - `claude-opus-4-20250514` (Claude Opus 4) - для генерации медицинских шаблонов
- **python-telegram-bot** - библиотека для Telegram Bot API
- **anthropic** - официальный SDK для Claude API

## Установка

### Требования

- Python 3.9 или выше
- pip (менеджер пакетов Python)
- Telegram Bot Token (получить у [@BotFather](https://t.me/botfather))
- Anthropic API Key (получить на [console.anthropic.com](https://console.anthropic.com))

### Шаги установки

1. Клонируйте репозиторий:
```bash
git clone <repository-url>
cd DOCUM
```

2. Создайте виртуальное окружение (рекомендуется):
```bash
python -m venv venv
source venv/bin/activate  # Linux/macOS
# или
venv\Scripts\activate  # Windows
```

3. Установите зависимости:
```bash
pip install -r requirements.txt
```

4. Создайте файл `.env`:
```bash
cp .env.example .env
```

5. Заполните переменные окружения в `.env`:
```env
TELEGRAM_BOT_TOKEN=your_telegram_bot_token_here
ANTHROPIC_API_KEY=your_anthropic_api_key_here
```

6. **ВАЖНО: Добавьте свои шаблоны осмотров**:
   - **Для клиники "Династия"**: создайте файл `data/templates/dinastiya/template.txt`
   - **Для клиники "ПСКП"**: создайте файл `data/templates/pskp/template.txt`

   Шаблоны должны содержать полную структуру медицинского осмотра с местами для подстановки данных пациента.

7. Запустите бота:
```bash
python main.py
```

## Использование

### Команды бота

- `/start` - Начать работу с ботом (показывает кнопки выбора клиники)
- `/help` - Получить помощь по использованию
- `/stats` - Статистика архива шаблонов

### Способы ввода данных

#### 1. Отправка фото документа (СНИЛС)

Просто отправьте фото документа боту. Бот автоматически распознает:
- ФИО
- Дату рождения
- СНИЛС (если есть на фото)

После распознавания отправьте диагноз текстом.

#### 2. Текстовый ввод

Отправьте данные в следующем формате:
```
ФИО: Иванов Иван Иванович
Дата рождения: 01.01.1990
СНИЛС: 123-456-789 00
Диагноз: Острый бронхит
```

СНИЛС не обязателен и может быть пропущен.

### Workflow использования

1. **Запустите бота** командой `/start`
2. **Выберите клинику** нажав на кнопку (🏥 Династия или 🏥 ПСКП)
3. **Отправьте данные**:
   - Фото СНИЛС + текст с диагнозом
   - ИЛИ всё данные текстом
4. **Проверьте шаблон** - бот создаст заполненный шаблон
5. **Выберите действие**:
   - ✅ **"Всё ОК, сохранить"** - шаблон сохраняется в архив
   - ✏️ **"Нужны правки"** - запросить исправления
6. **Если нужны правки**:
   - Отправьте комментарии текстом
   - Бот исправит шаблон
   - Снова проверьте и подтвердите
7. **Готово!** Шаблон сохранен в архив

## Как работает OCR

Бот использует **Claude Sonnet 4.5** (последняя модель 2025 года) для распознавания текста с фотографий:

1. Пользователь отправляет фото документа
2. Бот скачивает фото через Telegram API
3. Изображение конвертируется в base64
4. Отправляется в Claude API с промптом на извлечение данных
5. Claude распознает и извлекает структурированные данные (JSON)
6. Данные сохраняются в контекст пользователя

## Генерация шаблонов

Для генерации используется **Claude Opus 4**:

1. Бот загружает готовый шаблон для выбранной клиники из файла
2. Собираются все данные пациента (из фото или текста)
3. Из архива извлекаются похожие шаблоны по диагнозу (до 3 шт.)
4. Claude заполняет готовый шаблон с учетом:
   - Структуры шаблона клиники
   - Данных пациента
   - Диагноза
   - Контекста из похожих шаблонов
5. Заполненный шаблон отправляется пользователю для проверки

## Система исправлений

Если пользователь запрашивает правки:

1. Пользователь отправляет комментарии текстом
2. Claude Opus 4 анализирует текущий шаблон и комментарии
3. Вносит необходимые исправления, сохраняя структуру
4. Возвращает исправленный шаблон
5. Процесс можно повторять до полного утверждения

## Устранение проблем

### Бот не отвечает

1. Проверьте правильность `TELEGRAM_BOT_TOKEN`
2. Убедитесь, что бот запущен (`python main.py`)
3. Проверьте логи на наличие ошибок

### Ошибка распознавания фото

1. Проверьте `ANTHROPIC_API_KEY`
2. Убедитесь, что фото четкое и текст читаемый
3. Проверьте лимиты вашего Anthropic аккаунта

### Ошибка генерации шаблона

1. Проверьте, что шаблоны размещены в правильных папках:
   - `data/templates/dinastiya/template.txt`
   - `data/templates/pskp/template.txt`
2. Убедитесь, что указаны все обязательные поля (ФИО, дата рождения, диагноз)
3. Проверьте доступ к Claude API
4. Проверьте логи для детальной информации об ошибке
