# Telegram Medical Bot

Telegram бот для автоматического создания шаблонов медицинских осмотров с использованием Claude AI.

## Возможности

- **Распознавание фото документов (OCR)**: Автоматическое извлечение ФИО, даты рождения и СНИЛС с фотографий документов
- **Ввод данных текстом**: Возможность вручную ввести данные пациента
- **Генерация шаблонов осмотра**: Создание детальных медицинских шаблонов с учетом диагноза
- **Поддержка двух клиник**:
  - Клиника "Династия"
  - Клиника "ПСКП"
- **Архивирование шаблонов**: Сохранение всех созданных шаблонов с возможностью поиска
- **Контекстное обучение**: Использование похожих шаблонов из архива для улучшения качества

## Используемые технологии

- **Claude AI**:
  - `claude-3-5-sonnet-20241022` для OCR и распознавания документов
  - `claude-opus-4-20250514` для генерации медицинских шаблонов
- **Telegram Bot API**
- **TypeScript**
- **Node.js**

## Установка

### Требования

- Node.js >= 18
- npm или yarn
- Telegram Bot Token (получить у [@BotFather](https://t.me/botfather))
- Anthropic API Key (получить на [console.anthropic.com](https://console.anthropic.com))

### Шаги установки

1. Клонируйте репозиторий:
```bash
git clone <repository-url>
cd telegram-medical-bot
```

2. Установите зависимости:
```bash
npm install
```

3. Создайте файл `.env` на основе `.env.example`:
```bash
cp .env.example .env
```

4. Заполните переменные окружения в `.env`:
```env
TELEGRAM_BOT_TOKEN=your_telegram_bot_token_here
ANTHROPIC_API_KEY=your_anthropic_api_key_here
DEFAULT_CLINIC=dinastiya
```

5. Скомпилируйте TypeScript:
```bash
npm run build
```

6. Запустите бота:
```bash
npm start
```

Или для разработки с автоматической перезагрузкой:
```bash
npm run dev
```

## Использование

### Команды бота

- `/start` - Начать работу с ботом
- `/help` - Получить помощь по использованию
- `/clinic_dinastiya` - Переключить на клинику "Династия"
- `/clinic_pskp` - Переключить на клинику "ПСКП"
- `/stats` - Статистика архива шаблонов

### Способы ввода данных

#### 1. Отправка фото документа (СНИЛС)

Просто отправьте фото документа боту. Бот автоматически распознает:
- ФИО
- Дату рождения
- СНИЛС (если есть на фото)

После распознавания отправьте диагноз текстом.

#### 2. Текстовый ввод

Отправьте данные в следующем формате:
```
ФИО: Иванов Иван Иванович
Дата рождения: 01.01.1990
СНИЛС: 123-456-789 00
Диагноз: Острый бронхит
```

СНИЛС не обязателен и может быть пропущен.

### Пример использования

1. Запустите бота командой `/start`
2. Выберите клинику: `/clinic_dinastiya` или `/clinic_pskp`
3. Отправьте фото СНИЛС или введите данные текстом
4. Бот создаст шаблон медицинского осмотра
5. Шаблон будет сохранен в архив

## Как работает OCR

Бот использует Claude 3.5 Sonnet для распознавания текста с фотографий документов:

1. Пользователь отправляет фото документа
2. Бот скачивает фото через Telegram API
3. Изображение конвертируется в base64
4. Отправляется в Claude API с промптом на извлечение данных
5. Claude распознает и извлекает структурированные данные (JSON)
6. Данные сохраняются в контекст пользователя

## Генерация шаблонов

Для генерации используется Claude Opus 4:

1. Собираются все данные пациента (из фото или текста)
2. Определяется активная клиника
3. Из архива извлекаются похожие шаблоны по диагнозу
4. Claude генерирует новый шаблон с учетом:
   - Структуры шаблонов конкретной клиники
   - Данных пациента
   - Диагноза
   - Контекста из похожих шаблонов
5. Шаблон сохраняется в архив

## Шаблоны клиник

### Клиника "Династия"

Структура осмотра включает:
1. Анамнез (жалобы, история заболевания, аллергоанамнез)
2. Объективный осмотр (по системам)
3. Предварительный диагноз
4. План обследования
5. План лечения
6. Рекомендации

### Клиника "ПСКП"

Структура осмотра включает:
1. Жалобы и анамнез (anamnesis morbi, anamnesis vitae)
2. Status praesens (детальный осмотр всех систем)
3. Диагноз
4. Обследование
5. Назначения
6. Дневники наблюдения

## Архив шаблонов

Все созданные шаблоны сохраняются в директории `data/archive/` в формате JSON.

Структура файла шаблона:
```json
{
  "id": "uuid",
  "clinic": "dinastiya",
  "patientData": {
    "fullName": "Иванов Иван Иванович",
    "birthDate": "01.01.1990",
    "snils": "123-456-789 00",
    "diagnosis": "Острый бронхит"
  },
  "content": "Полный текст шаблона...",
  "createdAt": "2024-01-01T00:00:00.000Z"
}
```

## Устранение проблем

### Бот не отвечает

1. Проверьте правильность `TELEGRAM_BOT_TOKEN`
2. Убедитесь, что бот запущен (`npm start`)
3. Проверьте логи на наличие ошибок

### Ошибка распознавания фото

1. Проверьте `ANTHROPIC_API_KEY`
2. Убедитесь, что фото четкое и текст читаемый
3. Проверьте лимиты вашего Anthropic аккаунта

### Ошибка генерации шаблона

1. Проверьте, что указаны все обязательные поля (ФИО, дата рождения, диагноз)
2. Убедитесь, что есть доступ к Claude API
3. Проверьте логи для детальной информации об ошибке
